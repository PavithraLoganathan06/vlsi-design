# FinFET TCAD Simulation

3D FinFET device modeling and electrical characterization using Synopsys Sentaurus TCAD.

## Tools
- Sentaurus Structure Editor (SDE)
- Sentaurus Device (SDevice)
- Sentaurus Visual

## Work Done
- Designed a 3D FinFET structure using SDE.
- Defined device regions, materials, contacts, and doping profiles.
- Generated the device mesh for simulation.
- Performed electrical simulation using SDevice.
- Analyzed the simulated electrical characteristics.
